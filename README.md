# Retail Sales Analysis Project

## Project Overview

This project focuses on analysing retail sales data to understand business performance, customer purchasing behaviour, product performance, payment preferences, and geographical sales distribution.

The project uses Python, Pandas, and Power BI to transform raw retail data into meaningful business insights through data cleaning, analysis, and interactive visualisation.

## Project Objectives

- Analyse overall retail sales and profitability.
- Identify top-performing products and categories.
- Understand customer purchasing behaviour.
- Analyse payment methods and order patterns.
- Evaluate sales performance across different states and regions.
- Identify trends and opportunities for business improvement.

## Dataset Description

The project consists of six related datasets:

| Dataset | Description |
|---|---|
| Orders | Order-level information |
| Order Details | Product and quantity details for each order |
| Customers | Customer information and demographics |
| Products | Product names, brands, and categories |
| Stores | Store and geographical information |
| Payments | Payment methods and transaction details |

## Tools and Technologies

- Python
- Pandas
- Power Query
- Power BI
- DAX

## Project Workflow

1. Dataset exploration
2. Data cleaning and preprocessing using Python
3. Exploratory Data Analysis (EDA)
4. Data transformation using Power Query
5. Data modelling and relationship creation
6. DAX measures and calculations
7. Interactive dashboard development
8. Business insights and recommendations

## Power BI Dashboard

The interactive dashboard presents:

- Overall sales and profit performance
- Sales by product category
- Geographical sales distribution
- Customer segment and age-group analysis
- Monthly sales and profit trends
- Payment method analysis
- Category-level drill-through analysis

The dashboard currently displays the 2022 analysis.

## Key Findings

- Electronics and Groceries are leading sales-contributing categories.
- Maharashtra records the highest sales among the displayed states.
- The South region has the highest order distribution.
- Regular customers contribute strongly to sales.
- UPI is the most commonly represented payment method.
- Wearables is the highest profit-contributing Electronics subcategory.
