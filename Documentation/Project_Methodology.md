# Project Methodology – Retail Sales Analysis

## 1. Data Collection
Collected six related datasets: Orders, Order Details, Customers, Products, Stores, and Payments.

## 2. Data Exploration
Explored the datasets to understand their structure, columns, data types, and quality.

## 3. Data Cleaning
Used Python and Pandas to identify and handle:
- Missing values
- Duplicate records
- Incorrect data types
- Inconsistent text values
- Invalid values and outliers

## 4. Exploratory Data Analysis (EDA)
Analysed the data to identify sales trends, customer behaviour, product performance, and business patterns.

## 5. Data Transformation
Used Power Query to prepare and transform data for reporting.

## 6. Data Modelling
Created relationships between the six datasets in Power BI.

## 7. Data Analysis
Created DAX measures to calculate important business metrics such as:
- Total Sales
- Total Quantity
- Total Cost
- Total Profit
- Profit Margin

## 8. Dashboard Development
Developed an interactive Power BI dashboard to present key performance indicators, trends, and business insights.
